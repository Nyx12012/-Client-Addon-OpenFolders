# Open Folders

A TavernLauncher addon that adds buttons for opening your Mods and addons folders.

- **📁 Mods Folder**, next to 🧪 Mods on the main window. Opens the `Mods` folder of the game set at the
  top of the launcher.
- **📁 Addons Folder**, next to 🧩 Addons at the bottom of the main window. Opens the `addons` folder of
  the launcher you are using.
- **📁 Open Addons Folder**, under Save in the 🧩 Addons window. Same folder as above.

Works in both the Client and Server launchers. Tested on TavernLauncher 1.8.3, 1.8.4 and 1.8.5.

## Install

1. Download `OpenFolders-1.2.0.zip` from Releases and unzip it.
2. Copy the `openfolders` folder into the `addons` folder next to `TavernLauncher - Client.exe`
   (or `TavernLauncher - Server.exe`).
3. Open TavernLauncher, click **🧩 Addons**, tick **Open Folders**, click **Save**, then restart the launcher.
